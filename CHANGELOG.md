## How to Contribute to This Changelog

When creating pull requests, please add entries to the `[Unreleased]` section under the appropriate categories. The format should follow:

- Describe the change
- Use past tense ("Add feature" not "Adds feature")
- Reference relevant issues or PRs when applicable
- Use appropriate emoji indicators

Categories:
- **Added** for new features
- **Changed** for changes in existing functionality
- **Deprecated** for soon-to-be removed features
- **Removed** for now removed features
- **Fixed** for any bug fixes
- **Security** for security issue fixes
